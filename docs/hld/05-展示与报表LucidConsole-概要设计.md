# 05 · 展示与报表 LucidConsole — 概要设计

> 需求：R5（攻击详情/原始日志查阅导出 UI）、R6（15 天明细查询 UI）、R8（自定义报表）；内嵌 LucidBGP（R9）

## 1. 定位与边界

- **做**：Web 控制台（SPA）、API 网关（聚合 Analytics/Storage/Master/LucidBGP 后端）、报表中心（R8）、WebSocket 实时推送、RBAC 前端执行。
- **不做**：业务计算（各模块后端）、BGP 页面本体（LucidBGP 自带前端，iframe 集成）。

## 2. 技术栈

React 18 + TypeScript + Vite；图表 ECharts 5（矩阵热力图核心）+ AntV L7（地理）；状态 Redux Toolkit + RTK Query；UI 组件 Ant Design 5。后端网关：Go（`lucid-gateway`），单点接入所有 `/api/v1/*`。

## 3. 页面地图

| 分组 | 页面 | 承载需求 |
|---|---|---|
| 总览 | 大屏（全网/租户带宽、TopN、实时告警滚动） | — |
| 流量分析 | 流量矩阵（AS/前缀×维度热力、下钻）、多维分析、设备与接口（SNMP vs flow 对账）、客户域视图 | R4 边界接口展示 |
| 明细查询 | **15 天原始日志查询**（条件表单+结果表+异步导出入口） | **R6** |
| 安全 | 攻击中心（列表/实时）、攻击详情（分钟表格 R5 + 证据 + 一键导出原始日志 R5 + 一键处置→LucidBGP）、检测策略 | R2/R5/R7 |
| 报表 | **报表中心：模板管理/自定义设计器/实例查询/订阅** | **R8** |
| 路由 | LucidBGP 内嵌页（连接/监控/RIB/处置联动） | R9 |
| 管理 | 设备与接口（角色修正 R4）、Zone/客户管理、转发规则 R1、用户/租户/RBAC、系统与集群监控 | 各 R |

## 4. 实时通道
WebSocket：告警/攻击事件/TopN 刷新（SSE 备选）；断线重连+事件回放（Redis stream 游标）。

## 5. 关键指标
- 明细查询页：6h 窗口首屏 ≤6s（对应 dd/04 §2.3）；
- 攻击事件推送延迟 ≤2s（从 Analytics 发布）；
- 报表渲染：10 万单元格表格 ≤8s（虚拟滚动）。

## 6. 需求映射
R5 → 攻击详情页（dd/05 §3）；R6 → 明细查询页（dd/05 §2）；R8 → 报表中心（dd/05 §4）。
