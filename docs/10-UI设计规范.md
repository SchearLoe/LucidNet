# 10 · UI 设计规范（LucidDesign）— 图标库 · 页面风格 · 菜单命名

> 版本 v1.0｜属主：LucidConsole（dd/05）｜前端 agent 与 UI 开发的唯一权威
> 设计基调：运维型数据产品——**信息密度优先、数字可读性优先、一致性优先**；Ant Design 5 为基础组件库，本规范定义其上的业务层。

## 1. 设计原则

1. **密度**：单屏可见信息量优先于留白美感；表格一律紧凑密度（行高 32px）。
2. **数字为王**：所有指标数字使用等宽字体 + 右对齐；单位永不下沉到小数位混乱展示。
3. **语义色克制**：颜色只表达语义（入/出/攻击/基线/状态），不做装饰性用色。
4. **术语唯一**：界面用词以 §5 术语表为唯一权威，同一概念永不出现第二种叫法。
5. **暗色仅大屏**：控制台默认浅色主题；总览大屏用深色主题（§6），同一套 token 切换。

## 2. 图标库规范

### 2.1 分层

| 层 | 来源 | 用途 |
|---|---|---|
| 通用图标 | `@ant-design/icons` v5 | 增删改查、表单操作、状态等通用语义 |
| 业务图标 | 自研 `lucid-icons`（本规范 §2.3 清单） | 网络设备、流量、攻击、集群等业务概念 |
| 图表图形 | ECharts symbol / 自绘 SVG sprite | 拓扑图、矩阵中的图形元素 |

### 2.2 业务图标规格

- SVG 源文件：24×24 viewBox，线性风格，描边 1.5px，圆角端点，`stroke="currentColor"`（禁 fill 定色）；导出 16/20/24 三档使用，默认 16。
- 文件名：kebab-case，`<域前缀>-<含义>.svg`；域前缀见 §2.3。
- 工程化：源文件唯一存放 `web/packages/icons/svg/`；构建脚本（svgr）生成 React 组件（`IconDevRouter` 式 PascalCase）+ symbol sprite（供 ECharts/地图/富文本引用）；**禁止在页面里手写内联 SVG 路径**。
- 新增流程：PR 到 `icons` 包 → 维护者审查风格一致性（栅格/线宽/拐角）→ 更新 §2.3 清单。

### 2.3 初始业务图标清单（agent 按此表绘制）

| 前缀/域 | 图标（文件名） | 用途 |
|---|---|---|
| `dev-` 设备 | dev-router / dev-switch / dev-firewall / dev-host / dev-idc | 拓扑与设备选择器 |
| `net-` 网络 | net-link / net-interface / net-boundary / net-internal / net-peer / net-tunnel | 接口角色（R4）、对等连接 |
| `flow-` 流量 | flow-stream / flow-in / flow-out / flow-matrix / flow-topn / flow-export | 分析与导出 |
| `sec-` 安全 | sec-attack / sec-syn / sec-udp / sec-reflect / sec-sweep / sec-anomaly / sec-shield / sec-mitigate / sec-blackhole / sec-flowspec | 攻击类型（R2/R7）、处置（R9） |
| `sys-` 系统 | sys-node / sys-cluster / sys-db / sys-queue / sys-deploy / sys-audit / sys-report / sys-baseline | 部署（08）、监控、报表 |

## 3. 页面风格规范（Design Tokens）

### 3.1 色彩

**语义色（唯一色值，禁止页面内自定）**

| Token | 色值 | 用途 |
|---|---|---|
| `--lucid-primary` | `#2F6BFF` | 品牌主色、链接、主按钮、选中态 |
| `--lucid-in` | `#2F6BFF` | **流入流量**（客户视角 in）曲线/数字 |
| `--lucid-out` | `#FA8C16` | **流出流量**（out）曲线/数字 |
| `--lucid-attack` | `#F5222D` | 攻击/严重告警叠加层 |
| `--lucid-baseline` | `#8C8C8C`（虚线带 rgba .25） | 基线带/预测 |
| `--lucid-warning` | `#FA8C16` | 警告 |
| `--lucid-success` | `#52C41A` | 正常/恢复 |
| `--lucid-neutral` | `#8C8C8C` | 辅助文字、禁用 |

> 入=蓝、出=橙：色盲友好对比；攻击红只在攻击语义出现。所有曲线图 in/out 顺序与图例顺序固定：in 在前。

**分类色板（多序列图表，按序取色）**
`#2F6BFF, #13C2C2, #722ED1, #FA8C16, #52C41A, #EB2F96, #2F54EB, #A0D911, #F5222D, #00B8D4, #9254DE, #FAAD14`
> 超过 12 个序列必须分组/TopN 截断，禁止无限加色。

**流量矩阵热力 ramp（R5 矩阵页）**：单色蓝 5 档 `#E8F1FF → #B5CCFF → #6E96FF → #2F6BFF → #1D3FA0`；攻击行/格覆盖红 ramp（`#FFE8E8 → #F5222D`）；图例必须显示分档阈值。

**状态语义**：Established/正常=success、候选/警告=warning、确认/严重=attack 红、处置中=primary、已缓解/关闭=neutral。

### 3.2 字体与字号

| 场景 | 字体栈 |
|---|---|
| UI 文本 | `-apple-system, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif` |
| **数据（IP/端口/ASN/速率/时间戳/ID）** | `"JetBrains Mono", Consolas, "Sarasa Mono SC", monospace`（必用） |

- 字号阶梯：12 / 13 / 14（正文基准）/ 16 / 20 / 24；行高 1.5；下限 12px。
- 表格数字列：`font-variant-numeric: tabular-nums` + 等宽字体 + 右对齐。

### 3.3 数字与单位格式化（前端唯一实现：`shared/format.ts`，禁止页面自写）

| 量 | 规则 | 示例 |
|---|---|---|
| 带宽 | SI 十进制（K/M/G/T bps），3 位有效数字 | `1.23 Gbps`、`845 Mbps` |
| 包速率 | 同上 pps | `34.5 Kpps` |
| 字节 | SI（KB/MB/GB，10³），1 位小数 | `2.4 GB` |
| 数量（流/告警/前缀） | 千分位；≥1 亿显示 `1.2 亿`（表格）或 `120M`（图表） | `86,400` |
| 比例 | 百分比 1 位小数 | `73.4%` |
| 空值/零 | 无数据 `—`；0 与无数据严格区分 | |
| 采样加权值 | 数字后加角标 `※`，悬浮显示"按采样率还原的估算值" | `12.3 Gbps※` |

时间：存储 UTC，展示本地时区（页眉常显当前时区，可切 UTC）；绝对时间 `YYYY-MM-DD HH:mm:ss`；列表相对时间（"5 分钟前"）悬浮显示绝对值；图表时间轴 `HH:mm`（跨天加日期）。

### 3.4 布局与栅格

- 左侧导航 224px（可折叠 64px）；页头 48px（面包屑+租户+时区+用户）；内容区内边距 16px，卡片间距 12px。
- 支持 ≥1280px；≥1440 为设计基准。
- 页面模板四类（新页面必须套用其一）：**L1 列表筛选页**（过滤区+表格+分页）、**L2 详情页**（头部摘要卡 + Tabs）、**L3 仪表盘**（12 栅格卡片拖拽区）、**L4 向导**（Steps 分步）。

### 3.5 表格规范

紧凑密度（行高 32px）；数字列右对齐等宽；IP/端口/ID 用等宽字体；长列表（>200 行）虚拟滚动；空值 `—`；操作列固定右侧 ≤3 个按钮，更多进"…"菜单；列宽支持拖拽且用户偏好本地持久化。

### 3.6 图表规范（ECharts）

- 主题唯一来源：`web/packages/charts/theme.json`（从 §3.1 token 生成），**禁止页面内传色值**。
- 双轴规则：左轴带宽 bps、右轴 pps/新建流；网格线仅横向；图例左上；tooltip 十字准线。
- 基线带画法：中位数实线灰 + ±MAD 半透明带；攻击时段竖向红色半透明区间 + 起止标注（R5 详情页标准画法）。
- 采样数据曲线必须在副标题标注"※ 估算（采样率 N:1）"。

### 3.7 状态与反馈

加载 ≥300ms 显示骨架屏（表格显示 5 行灰条）；空态给"下一步指引"（如明细无数据→提示检查过滤条件/时间窗）；错误态显示可复制的 `trace_id` + 重试按钮；WebSocket 断连页面顶部黄条"实时推送已断开，正在重连"。

## 4. 主题实现

- 所有颜色/字号/间距经 CSS 变量 `--lucid-*` 声明（`web/packages/shared/tokens.css`）；AntD 5 用 `ConfigProvider theme` 映射同名 token；**组件禁止硬编码色值/字号**。
- 深色主题 = 同名 token 覆盖（`[data-theme="dark"]`）；ECharts 主题运行时读取 CSS 变量生成，保证两主题一致。

## 5. 菜单与信息架构命名规范

### 5.1 命名规则

1. 一级菜单 ≤4 个汉字，二级 ≤6 个汉字；同层词性一致（名词优先）。
2. 全系统唯一术语（§5.3 术语表）；禁止同义词混用。
3. 操作型入口用动宾结构（"下发处置"）；查看型用名词（"攻击中心"）。
4. 禁止中英混排；协议/产品专有名除外（BGP、SNMP、IPv6）。
5. 数字规范：阿拉伯数字 + 空格 + 单位（"15 天明细"）。
6. 按钮 ≤4 字动词（查询/导出/处置/撤销/重试）；危险操作红色 + 二次确认（输入集群名级别）。
7. **路由与菜单解耦**：路由一律英文 kebab-case，菜单显示中文；对照关系唯一维护在 `web/src/menus.ts`（含权限码），下表即其初始内容。

## 6. 大屏（总览页）专项

深色主题底 `#0A0F1E`；图表透明卡片（描边 1px rgba(255,255,255,.08)）；数字放大（24px 等宽）；无滚动条单屏布局；刷新间隔 ≥5s 且显示数据时间戳；投影环境对比度按 WCAG AA（≥4.5:1）校验。
