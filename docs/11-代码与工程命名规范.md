# 11 · 代码与工程命名规范

> 版本 v1.0｜适用全部模块 agent｜与 09 接口契约同级权威；语言官方风格优先，本规范定义补充与跨语言统一项

## 1. 总则

1. 一律英文命名；禁止拼音（专有名词除外：NetStream、gobgpd）。
2. 缩写白名单（超出须写全）：`id, ip, tcp, udp, bgp, snmp, as(Autonomous System), ts, ttl, cfg, ctx, db, http, uri, id, oid, tz`。
3. 禁用包/模块名：`util, common, misc, base, helpers, lib`——按职责拆具体名（如 `timeutil` → `clock`、`flowutil` → `flowfmt`）。
4. 单复数：类型/函数单数；集合/表复数（`devices` 表存多个 device）。

## 2. 仓库结构（Go 单仓 monorepo）

```
lucidnet/
├── cmd/                    # 每二进制一目录：cmd/lucid-broker|lucid-collector|lucid-analytics|
│   |                       #   lucid-rib-feeder|lucid-exporter|lucid-reporter|lucid-gateway|lucid-master|lucid-agent|lucidctl
├── internal/               # 各模块包（不对外）：internal/collector/{decoder,enrich,zone,snmp} 等
├── pkg/                    # 确需跨二进制共享的库（少量）
├── proto/lucidnet/v1/      # 00/09 契约（唯一来源）
├── gen/{go,java,ts}/       # 生成代码（禁止手改）
├── migrations/             # DB 迁移（§7）
├── web/                    # 前端 pnpm workspace（dd/05 §1：web/shared/charts/icons）
├── bgp/                    # LucidBGP 子仓引用/镜像 jar 构建（dd/06）
├── scripts/                # 部署白名单脚本（dd/08 §3.3）
└── docs/                   # 本设计文档体系
```

## 3. Go 规范（Broker/Collector/Analytics/Storage/Master/Deploy）

- 包名：小写单词、与目录同名、不用下划线；`internal/<module>/<domain>` 两级。
- 文件名 snake_case；测试 `*_test.go`；表驱动测试优先。
- 导出标识 PascalCase；接口按 Go 惯例（`-er` 后缀或行为名）；错误：`fmt.Errorf("decode v9 template for %s: %w", exporter, err)`——小写开头、无标点结尾、必须 `%w` 包裹。
- context 首参；配置用 Option 模式；结构体构造函数 `NewXxx`。
- 常量枚举用 typed enum：`type IfRole uint8` + `IfRoleBoundary`（**禁止魔法数字**，语义对照见 09 §3）。
- lint：golangci-lint（revive + govet + staticcheck），CI 强制。

## 4. Java（LucidBGP，遵循 dd/06 改名清单）

- 包 `com.lucidnet.bgp.*`；REST 路径 `/api/bgp/**`；配置键 `lucidbgp.*`（kebab-case）。
- 沿用 rsbgp-console 既有命名惯例（`XxxController / XxxBuilder / PathViews`），重构仅限改名清单范围。

## 5. TypeScript / React（web/）

| 项 | 规范 | 示例 |
|---|---|---|
| 组件 | PascalCase 文件与名 | `AttackDetail.tsx` |
| Hooks | `use` 前缀 camelCase | `useAttackStream.ts` |
| API 模块 | `*.api.ts`，函数 camelCase 动词开头 | `searchFlows()` / `createExportJob()` |
| 类型 | proto 生成为准（gen/ts），本地类型 PascalCase | `AttackEvent` |
| 常量 | UPPER_SNAKE_CASE | `MAX_QUERY_WINDOW_H` |
| 路由 | kebab-case（§10 菜单表对照） | `/security/attacks/:id` |
| 权限码 | `<domain>:<action>`（§8） | `flows:export` |
| 样式 | AntD token + `--lucid-*` CSS 变量；禁止内联 hex/px 字号 | — |
| 格式化 | 数字/时间只经 `shared/format.ts`（doc10 §3.3） | — |

lint：eslint + prettier；CI 强制；禁止 `any`（proto 生成类型除外需显式注释）。

## 6. proto / Kafka（详见 00/09，此处仅命名）

- proto：包 `lucidnet.v1`；文件 snake_case；message PascalCase；字段 snake_case；枚举值大写下划线并带类型前缀（`ZONE_SIDE_DST`）。
- Kafka：topic / 消费组命名与登记以 09 §2 为唯一权威；消息 key 编码变更=破坏性契约变更。

## 7. 数据库

- PostgreSQL：表/列 snake_case，业务表**复数**（devices, zones, users, export_jobs）；索引 `idx_<表>_<列…>`，唯一 `uq_<表>_<列>`；外键不建物理约束（应用层保证）。
- ClickHouse：数据面表**单数 + 语义后缀**（`flows_raw / aggr_minute / aggr_hour / attack_minutes`）；物化视图 `mv_<目标表>_<来源>`；字典 `dict_<名>`。
- 迁移文件：`migrations/<序号4位>_<desc>.sql`（PG）；CH DDL 变更走 `migrations/ch/`；禁止修改已合入的历史迁移文件。

## 8. 配置、环境变量与权限码

- 环境变量：`LUCID_<组件>_<键>` UPPER_SNAKE（`LUCID_COLLECTOR_KAFKA_BROKERS`）。
- etcd 键：以 09 §5 为唯一权威；新增键需登记。
- 配置文件键：Go/JSON 走 proto JSON（snake_case）；Spring kebab-case（`lucidbgp.gobgp-target`）。
- 权限码：`<domain>:<action>`；domain 白名单 `overview | analysis | flows | attack | policy | report | bgp | admin | zone | device | forward | audit | monitor | deploy`；action 白名单 `read | edit | export | handle | manage | install | upgrade | rollback`。组合以 doc10 §5.2 菜单表为初始登记，新增需同步 Master 权限清单（dd/07 §4）。

## 9. 可观测性命名

- Prometheus 指标：`lucid_<组件>_<名词>[_<单位后缀>]`；基础单位（`_seconds/_bytes`），速率在查询层算（不存速率型 gauge 命名）；计数器必须 `_total`；直方图 `_seconds` bucket。
  - 示例：`lucid_collector_flow_records_total{exporter=…}`、`lucid_analytics_detect_latency_seconds`、`lucid_storage_insert_batch_bytes`。
- 标签白名单（值小写枚举）：`exporter, device_id, zone_id, node, rule_id, dest, direction(in|out), ip_version(v4|v6), topic, group`；**禁止高基数标签**（IP 地址、attack_id 只进日志不进标签）。
- 日志：JSON 单行；固定字段 `ts, level, module, msg, trace_id, node, err` + 业务字段 snake_case；trace 经 Kafka header `x-lucid-trace-id` 贯穿 Collector→Analytics→Inserter。
- Grafana 面板/告警规则命名：`[<组件>] <对象> <指标>`（`[collector] exporter 丢包率`）。

## 10. 制品、镜像与 Git

- 容器镜像：`ghcr.io/schearloe/lucidnet/<组件>:<semver>`（`lucidnet/collector:v1.0.0`；latest 禁止进生产）。
- 离线制品：`lucidnet-v<semver>-linux-amd64.tar.gz`（dd/08 §1.2）。
- 分支：`<type>/<module>-<slug>`（`feat/collector-huawei-ie`、`fix/analytics-sweep-hll`）；type ∈ feat|fix|chore|docs|refactor|test。
- 提交信息：`<module>: <摘要>`（CONTRIBUTING §提交流程）；tag：`v<semver>`（dd/08 §1.1 语义）。

## 11. CI 命名检查清单（M1 起入流水线）

1. golangci-lint / eslint / buf lint 全绿；
2. 迁移文件序号连续且历史未修改；
3. Prometheus 指标命名 lint（正则 `^lucid_[a-z]+_[a-z_]+(_total|_seconds|_bytes|_ratio)?$`，标签在白名单内）；
4. 前端禁内联色值扫描（`#[0-9a-fA-F]{3,8}` 出现在 .tsx 即失败，tokens/icons 包除外）；
5. 权限码与 etcd 键变更必须命中登记表（CI 比对 doc10 §5.2 / 09 §5 生成的清单）。
